# ChatMem v1.2.6

v1.2.6 focuses on keeping up with ZCode's new local storage, making every conversation open fast, and giving the library clearer sorting controls.

## What's New

### ZCode Reads The New Local Store

- ZCode conversations now load from ZCode's own session store (`~/.zcode/cli/db/db.sqlite`), so built-in GLM sessions show their full message history instead of a text fallback.
- The ZCode source no longer requires the legacy `acp-config` folder, so fresh ZCode installs list their conversations too.
- Subagent-style hidden system messages are filtered out of imported conversations.
- Old `v2/sessions` task files are parsed with a light summary pass plus an in-memory cache, so the ZCode list no longer re-reads hundreds of megabytes on every refresh.
- ZCode Codex threads whose rollout files are gone no longer appear as entries that always fail to open.

### Much Faster Conversation Opens

- Opening a conversation no longer rebuilds the search index on the UI path: reads parse in the background and the snapshot sync happens off the critical path.
- Per-document FTS maintenance is batched during snapshot rebuilds, cutting a large rebuild from ~19 seconds to under 1 second.
- Added database indexes for messages, tool calls, file changes, and search documents, and switched the local store to WAL mode so background imports no longer block the app.
- Imports and repo scans skip conversations whose source has not changed, and no longer abort when a single conversation fails to read.

### Clearer Library Sorting

- A "Recently updated" quick toggle in the library header shows the conversations with the freshest updates first, regardless of when they were created.
- Created-time ordering lives in the organize menu as two explicit options: newest created first and oldest created first.
- The sorting choice persists across restarts and applies to every conversation source.
- The manage-groups button was removed; machine groups remain visible in the library.

### Lucide Icons And A Resizable Sidebar

- All icons now come from the Lucide set drawn with thin strokes.
- The divider between the sidebar and the detail panel can be dragged to resize, double-clicked to reset, and the width is remembered.
- Fixed clipping that cut off the organize menu and hover tooltips inside the sidebar.
