# ChatMem v1.2.5

v1.2.5 focuses on making ChatMem easier to release, easier to set up, and quieter to use day to day.

## What's New

### Cleaner Settings

- Settings now use a left navigation and focused right-side panels.
- Conversation sync, updates, agent setup, and About are separated into simpler pages.
- The About page now shows only the current version, key changes, project link, and references.

### Agent-First Memory

- Memory suggestions and startup rules are now review surfaces in the desktop app: users can view or delete them.
- Supported agents handle saving useful suggestions as rules through ChatMem setup.
- Agent Integration now uses clearer status labels such as Ready, Needs update, and Not set up.

### Better Codex Setup

- ChatMem keeps the shared skill in `.agents/skills/chatmem`.
- Older duplicate Codex skill copies are detected and cleaned up.
- Outdated agent instructions are shown as updateable instead of repair-only.

### Faster Project Recall

- `recall_project_work` is the default compact recall entrypoint for supported agents.
- Local-history recall now presents source snippets in a more readable way.
- Pending suggestions and project indexing status are easier to understand.

### Update And Packaging Readiness

- Update settings now focus on update checks and local data availability.
- Local data checks use user-facing labels such as App settings and Local memory.
- The release workflow keeps Windows, portable, macOS, and updater assets aligned.

## Download

Use the assets on the GitHub release page:

- Windows installer: `.exe`
- Windows portable build: `ChatMem-v1.2.5-portable.zip`
- macOS Apple Silicon: `ChatMem-v1.2.5-macOS-Apple-Silicon.dmg`
- macOS Intel: `ChatMem-v1.2.5-macOS-Intel.dmg`

Do not install from GitHub's source code zip or tarball.
