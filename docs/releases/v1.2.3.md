# ChatMem v1.2.3

发布日期：2026-06-30

## 重点更新

- 侧栏会检测可能重复的对话，并提示用户进入“处理重复”弹窗。
- 重复组会展示来源、消息数、文件变更数、更新时间和对话 ID，默认推荐保留更完整或更新的一份。
- ChatMem 不会自动删除重复对话；用户需要明确选择保留哪一份，未保留的候选会走现有垃圾箱确认流程。
- 本地历史导入不再静默选择 ZCode 迁移后的重复快照，而是把候选留给用户判断。
- 保留 v1.2.2 的 ZCode task-index、rollout history、GLM/ZCode 发现改进。
- 保留更宽松的应用内更新提示卡片，提供“立即安装”和“本次忽略”操作。

## 推荐下载

- Windows 安装包：`ChatMem_1.2.3_x64-setup.exe`
- Windows 便携版：`ChatMem-v1.2.3-portable.zip`
- macOS Apple Silicon：`ChatMem-v1.2.3-macOS-Apple-Silicon.dmg`
- macOS Intel：`ChatMem-v1.2.3-macOS-Intel.dmg`

普通用户请下载上面的安装包或便携包，不要下载 GitHub 自动生成的 source code zip/tar.gz。

macOS 构建目前未做 Apple Developer ID 签名和 notarization，首次启动可能需要在系统安全设置中允许打开。
