# ChatMem v1.2.4

发布日期：2026-06-30

## 重点更新

- 处理疑似重复对话时，点选候选项会轻量加载前几条消息预览，方便用户确认哪一份该保留。
- 重复候选预览只读取有限消息窗口，避免长对话在重复处理弹窗里造成卡顿。
- 移到垃圾箱或清空垃圾箱后，侧栏和重复识别会立即移除已处理候选，减少旧重复项短暂残留。
- 对话列表和搜索结果会排除仍在垃圾箱中的 original id，避免本地适配器、同步文件夹或 memory store 把已删候选又合回来。
- 保留 v1.2.3 的手动重复处理流程：ChatMem 不会自动删除重复对话，用户仍需要明确选择保留哪一份。
