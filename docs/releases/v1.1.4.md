# ChatMem v1.1.4

v1.1.4 is a focused release after v1.1.3. It improves conversation reading order and loading behavior, tightens the desktop layout, moves About into Settings, and keeps the newer continuation and Favorites workflows available.

## Highlights

- Conversation detail now starts from the first message and loads later messages with a `显示后续消息` control.
- Small conversations load fully instead of showing empty detail pages or misleading pagination actions.
- Large conversations use message windows only when they exceed the initial threshold.
- The sidebar collapse button now sits to the left of the logo and aligns with it vertically.
- The main conversation surface keeps its rounded inset when the window is maximized.
- About ChatMem now lives inside Settings instead of being a separate sidebar utility item.
- Added lightweight rendering constraints for long conversation lists and message cards.
- Summary-style migration and Favorites remain available in this release.
- Bumped app/package versions to `1.1.4`.

## What Changed

### Conversation Loading

ChatMem now treats the beginning of a conversation as the default reading position. When a conversation has more messages than the initial window, the detail view shows the first batch and lets users load the following messages on demand.

For small conversations, ChatMem skips server-side pagination entirely. This prevents short conversations from rendering only metadata with a stale `显示更早消息` action.

### Layout

The sidebar collapse control is now part of the top bar, positioned just before the logo. The workspace surface keeps its rounded container at fullscreen size so the right edge no longer appears clipped.

### Settings and About

The About page is embedded in Settings, alongside version, release notes, project links, and design acknowledgements. The sidebar utility navigation stays focused on daily actions.

### Continuation and Favorites

The release keeps the summary-style migration workflow for source-backed continuation briefs and the Favorites sidebar entry for important conversations.
